# AmazonTest

Selenium automation testing project for the Amazon website.

## Description

This project uses Selenium WebDriver with Java to automate testing of the Amazon website. It tests the search functionality, product selection, and add-to-cart process.

## Test Scenario

1. Open Amazon homepage.
2. Search for "Wireless Noise Cancelling Headphones, 120H Playtime, Over Ear Headphones".
3. Select the first product from search results.
4. Add the product to the cart.
5. View the cart.

## Technologies Used

- Java 21
- Selenium WebDriver 4.15.0
- Maven
- NetBeans 18
- ChromeDriver

## How to Run

1. Clone the repository.
2. Open the project in NetBeans.
3. Update the ChromeDriver path in `AmazonTest.java`.
4. Run the file.
